# Função e Objetivo
Atue como um Engenheiro de Software Sênior especialista em React, TypeScript e Computação Gráfica Web (WebGL/Three.js). 
O objetivo é criar uma Plataforma Web Interativa 3D para apresentação de projetos de fachadas comerciais em ACM (Alumínio Composto).

# Contexto do Projeto
A aplicação deve ser moderna, rápida e livre de travamentos. Ela servirá como um módulo de apresentação para clientes, alinhada aos padrões de comunicação visual da Decore e projetada com uma arquitetura escalável para futura integração com o sistema GRAFIO ERP. 

# Stack Tecnológica
- Frontend: React (v18+) com TypeScript.
- Estilização: Tailwind CSS.
- Motor 3D: @react-three/fiber (R3F) e @react-three/drei.
- Backend/Storage (Mock/Preparação): Supabase.

# Especificações de Arquitetura e UI
A interface deve seguir um padrão "Overlay", onde o Canvas 3D ocupa 100% da tela (z-index 0) e os menus flutuam sobre ele com efeito *glassmorphism* (fundo translúcido com desfoque).
1. **Header Flutuante:** Contendo a logo/título e o botão de alternância global "Dia / Noite".
2. **Painel Lateral de Configurações:** Contendo ferramentas de upload, ajuste de materiais e troca de ambiente.

# Funcionalidades Principais (Requisitos Técnicos)

## 1. Visualizador 3D (Canvas Base)
- Implementar `<Canvas>` do R3F ocupando toda a tela com suporte a sombras habilitado.
- Utilizar `<OrbitControls>` com limites de ângulo polar (para impedir que o cliente olhe por baixo do chão).
- Implementar `<ContactShadows>` do Drei para gerar sombras realistas no piso sem comprometer a performance.

## 2. Upload e Preview Instantâneo de Modelos (.glb / .gltf)
- Criar um componente de *drag and drop* e *input file* no painel lateral.
- Quando o usuário selecionar um arquivo `.glb`, o sistema não deve fazer upload para o servidor imediatamente. 
- Utilizar `URL.createObjectURL(file)` para gerar uma URL local temporária.
- Passar essa URL para um componente dinâmico usando o hook `useGLTF` (com suporte nativo à compressão Draco).
- Deixar a função `uploadToSupabase(file)` estruturada e comentada para envio assíncrono posterior em background.

## 3. Iluminação Dinâmica (Ciclo Dia e Noite)
- Estado global `isNightMode` gerenciando a iluminação.
- **Modo Dia:** Carregar `<Environment preset="city" />`, `<ambientLight intensity={0.8} />` e uma `<directionalLight>` forte gerando sombras duras para simular o sol.
- **Modo Noite:** Mudar o preset do `<Environment>` para "night", reduzir a luz ambiente, e simular luzes de refletores focados na fachada (utilizando `SpotLight`).

## 4. Mapa do Entorno (Background 360)
- O fundo não pode ser branco. Implementar a propriedade `background` no componente `<Environment>`.
- Deixar a estrutura pronta para receber um arquivo `.hdr` ou `.jpg` equiretangular (imagem 360 da rua do cliente) carregado via input.
- Adicionar um controle deslizante de `blur` no painel para que o usuário possa desfocar o ambiente e focar apenas na fachada, se desejar.

## 5. Materiais Realistas (Simulação de ACM)
- Configurar os nós do modelo importado para aceitar alterações de textura via UI.
- Garantir que os materiais aplicados à fachada utilizem `MeshStandardMaterial` com propriedades realistas para ACM: 
  - Superfície ligeiramente metálica (metalness ~0.3).
  - Reflexo ajustável (roughness variando entre 0.2 para brilho e 0.6 para fosco).

# Regras de Código e Performance
- Separe os componentes em arquivos distintos (ex: `UIOverlay.tsx`, `Scene3D.tsx`, `ModelLoader.tsx`).
- Otimize o re-render: Apenas as mudanças na UI devem renderizar novamente os componentes React; o Canvas 3D deve manter sua estabilidade.
- Escreva código limpo, devidamente tipado e com comentários em português explicando a lógica de carregamento assíncrono dos modelos 3D.
- Inicie o projeto gerando a estrutura completa de pastas e o código dos componentes essenciais de imediato.
